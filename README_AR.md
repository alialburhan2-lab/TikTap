# TikTap 0.2.0 — مشروع Android

تطبيق Java بواجهة عربية RTL يتضمن:
- فتح تطبيق TikTok المثبّت، أو فتح موقع TikTok في المتصفح إن لم يكن التطبيق متاحاً.
- مختبر نقرات آلي داخلي لقياس التكرار والسرعة داخل واجهة TikTap نفسها.
- تشغيل وإيقاف، سرعة قابلة للتعديل، عدّاد نقرات، وزر عدّ يدوي وتصفير.
- GitHub Actions لبناء APK تجريبي.

**حدود الإصدار:** لا ينفّذ نقرات على الشاشة في التطبيقات الخارجية ولا ينفّذ إعجابات تلقائية في بثوث TikTok. العداد الآلي يختبر المؤقّت داخل TikTap فقط.

## البناء
من مجلد المشروع:

```bash
gradle assembleDebug
```

أو ارفع المشروع إلى GitHub وشغّل Actions → Build TikTap APK → Run workflow. ينتج الملف `app/build/outputs/apk/debug/app-debug.apk` كـ artifact باسم `TikTap-debug-apk`.

يتطلب البناء Android SDK Platform 35 وJava 17 وGradle 8.9 أو بيئة GitHub Actions المعرّفة في `.github/workflows/android.yml`.


## الواجهة العائمة (0.3.0)
- افتح TikTap واضغط «تفعيل الواجهة العائمة».
- اسمح للتطبيق بالظهور فوق التطبيقات من إعدادات Android، ثم ارجع واضغط الزر مرة ثانية.
- تظهر لوحة قابلة للسحب فوق الشاشة: فتح TikTok، تسجيل ضغطات يدوية، وإخفاء اللوحة.
- اللوحة لا تضخ نقرات إلى تطبيقات أخرى ولا تنفّذ إعجابات تلقائية.


## الإصدار 0.4.0
- لوحة عائمة قابلة للسحب فيها بدء/إيقاف جلسة اختبار، وضبط الفاصل الزمني، وعدّاد.
- حقول إحداثيات اختبار داخل واجهة TikTap.
- خدمة Accessibility اختيارية بموافقة المستخدم، تعمل بوضع المراقبة فقط ولا تنقر داخل التطبيقات الأخرى.
- لا ينفّذ التطبيق نقرات تلقائية أو إعجابات داخل TikTok.
