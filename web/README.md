# غسان البرهان | المنصة الرسمية

> «الكلمة موقف.. والفكر مساحة»

منصة صحفية وثقافية متكاملة (عربية RTL) لنشر المقالات والتحليلات والحوارات والدراسات والآراء، مع لوحة إدارة كاملة على المسار `/admin` تتيح الكتابة والنشر دون أي تعديل برمجي.

**التقنيات:** Next.js 15 (App Router) · TypeScript · Tailwind CSS 4 · PostgreSQL · Prisma 6 · Auth.js v5 · TipTap · Sharp · Vitest · Playwright

---

## المتطلبات

- Node.js 20.9 أو أحدث
- PostgreSQL 14 أو أحدث (يجب أن يسمح المستخدم بإنشاء الامتداد `pg_trgm`، وهو امتداد موثوق في PostgreSQL 13+)

## التثبيت والتشغيل محلياً

```bash
cd web
npm install
cp .env.example .env          # ثم عدّل القيم (قاعدة البيانات، AUTH_SECRET، حساب المالك)
npx prisma migrate deploy     # إنشاء الجداول
npm run db:seed               # حساب المالك + التصنيفات (+ بيانات تجريبية إذا SEED_DEMO=true)
npm run dev                   # http://localhost:3000
```

لوحة الإدارة: `http://localhost:3000/admin`، وتسجيل الدخول بالقيم `ADMIN_EMAIL` و`ADMIN_PASSWORD` من ملف `.env`.

لتوليد `AUTH_SECRET`:

```bash
openssl rand -base64 32
```

### البيانات التجريبية

عند `SEED_DEMO=true` تُنشأ مقالات تجريبية **مُعلّمة بوضوح** بالوسم «محتوى تجريبي» في كل مكان. يُستثنى هذا المحتوى من خريطة الموقع، ويُضبط على noindex. يُنشأ أيضاً حسابان لاختبار الصلاحيات:

| الحساب | الدور | كلمة المرور |
|---|---|---|
| `editor@demo.local` | EDITOR | `Demo#Pass2026` |
| `author@demo.local` | AUTHOR | `Demo#Pass2026` |

> **قبل الإطلاق:** احذف المقالات التجريبية والحسابين من لوحة الإدارة (أو شغّل seed مع `SEED_DEMO=false` على قاعدة بيانات جديدة). لم تُختلق أي سيرة ذاتية أو مناصب أو مقالات منسوبة إلى الكاتب. نصوص السيرة والصفحات القانونية افتراضية، ويجب تحريرها من لوحة الإدارة.

### صفحات الموقع

الرئيسية `/` · المقالات `/articles` · الأقسام `/category/politics` (سياسية) و`/category/analysis` (تحليلات) و`/category/interviews` (حوارات) و`/category/studies` (دراسات) و`/category/opinion` (رأي) · الأرشيف `/archive?year=&month=` · الكاتب `/about` · اتصل بنا `/contact` · البحث `/search` · المقال `/article/[slug]` · الوسم `/tag/[slug]` · الخصوصية `/privacy` · الشروط `/terms` · `/sitemap.xml` · `/robots.txt`

الأقسام نفسها تُدار من قاعدة البيانات، ويمكن إضافة أقسام جديدة من لوحة الإدارة فتظهر في القائمة تلقائياً.

### لوحة الإدارة

لوحة التحكم · المقالات (إنشاء، تعديل، معاينة، نشر، أرشفة، حذف مع تأكيد) · التصنيفات · الوسوم · الوسائط · التعليقات · رسائل التواصل · مشتركو النشرة (مع تصدير CSV) · الإحصائيات · المستخدمون والصلاحيات · بيانات الكاتب · إعدادات الموقع (الهوية، خلفية القسم الرئيسي، الشبكات الاجتماعية، الصفحات القانونية) · الملف الشخصي.

### الأدوار والصلاحيات

تُدار الصلاحيات من مكان واحد هو `src/lib/permissions.ts`.

| | OWNER | EDITOR | AUTHOR |
|---|:-:|:-:|:-:|
| كتابة المقالات | ✔ | ✔ | ✔ (مسوداته فقط) |
| تعديل مقالات الآخرين | ✔ | ✔ (المسودات/قيد المراجعة) | ✘ |
| النشر / الجدولة / الأرشفة | ✔ | ✘ (يرسل للمراجعة) | ✘ (يرسل للمراجعة) |
| التصنيفات، الوسوم، التعليقات، كل الوسائط | ✔ | ✔ | ✘ |
| الإحصائيات | ✔ | ✔ | ✘ |
| المستخدمون، الإعدادات، بيانات الكاتب، الرسائل، المشتركون | ✔ | ✘ | ✘ |

لا يستطيع أي مستخدم تغيير دوره بنفسه، ولا يمكن حذف آخر مالك نشط أو تخفيض صلاحياته. يُقرأ الدور من قاعدة البيانات في كل طلب، فيُطبَّق أي تغيير عليه فوراً.

### حالات المقال

`DRAFT` مسودة · `REVIEW` قيد المراجعة · `SCHEDULED` مجدول (يظهر تلقائياً عند حلول موعده دون حاجة إلى Cron) · `PUBLISHED` منشور · `ARCHIVED` مؤرشف (مخفي عن الزوار).

## الأمان

- حماية `/admin` عبر Middleware، مع تحقق إضافي على الخادم في كل صفحة وكل Server Action.
- تجزئة كلمات المرور باستخدام bcrypt (12 جولة)، ومقاومة هجمات التوقيت.
- تحديد محاولات الدخول: 5 محاولات فاشلة لكل بريد و20 لكل عنوان IP خلال 15 دقيقة، مع التخزين في قاعدة البيانات.
- التحقق من جميع المدخلات على الخادم باستخدام Zod.
- تنظيف HTML (sanitize-html) عند الحفظ وعند العرض، وإضافة `rel="noopener noreferrer nofollow"` للروابط الخارجية.
- CSRF: تتحقق Server Actions من الأصل (Origin) تلقائياً في Next.js، وتتحقق مسارات API من الأصل يدوياً، وتستخدم Auth.js رمز CSRF.
- رفع الملفات: تحقق من الصلاحية، وفحص المحتوى الفعلي للصورة، وحد للحجم، وإعادة ترميز إلى WebP مع إزالة EXIF، وأسماء عشوائية، ومنع Path traversal.
- ترويسات أمان: CSP و HSTS و X-Frame-Options و nosniff و Referrer-Policy و Permissions-Policy.
- مصيدة Honeypot وتحديد معدل للتعليقات ونموذج الاتصال والنشرة.
- الإحصائيات بلا ملفات تعريف ارتباط، ولا تُخزَّن عناوين IP صراحة (تُخزَّن تجزئة مملّحة يومية فقط).
- منع حقن الصيغ في ملف CSV المُصدَّر.
- جميع المفاتيح السرية في متغيرات البيئة على الخادم فقط.

## الصور والتخزين

`STORAGE_DRIVER=local` (الافتراضي): تُحفظ الملفات في `UPLOAD_DIR` خارج `public` وتُخدم عبر `/uploads/...`. على الخوادم ذات القرص المؤقت (مثل Vercel) استخدم:

```
STORAGE_DRIVER=cloudinary
CLOUDINARY_CLOUD_NAME=...
CLOUDINARY_API_KEY=...
CLOUDINARY_API_SECRET=...
```

لإضافة مزود تخزين آخر (S3 أو R2 مثلاً)، أنشئ ملفاً جديداً في `src/lib/storage/` يطبّق الواجهة `StorageDriver`، ثم سجّله في `getDriver()`.

صور الكاتب المرفقة موجودة في `public/images/author/`. الخلفية الافتراضية للقسم الرئيسي هي `hero-books.webp`، ويمكن تغييرها من «إعدادات الموقع». الصورة الشخصية الافتراضية هي `portrait.webp`، ويمكن تغييرها من «بيانات الكاتب». صور معرض صفحة الكاتب معرّفة في `src/lib/author-photos.ts`.

## اللغات

الواجهة عربية RTL، والنصوص في `src/i18n/ar.ts`. لإضافة الإنجليزية لاحقاً:

1. أنشئ `src/i18n/en.ts` بالبنية نفسها، وأضف `"en"` إلى `locales`.
2. انقل `app/(site)` إلى `app/[locale]/(site)`، واضبط `dir` حسب اللغة.
3. حقل `locale` موجود مسبقاً في المقالات والتصنيفات، لذا لا يلزم تعديل قاعدة البيانات.

## النشر للإنتاج

### على خادم (VPS أو Docker)

```bash
cd web
npm ci
npx prisma migrate deploy
npm run db:seed            # مرة واحدة: SEED_DEMO=false
npm run build
npm start                  # يُفضَّل تشغيله خلف Nginx مع HTTPS، وإدارته عبر pm2 أو systemd
```

احرص على حفظ مجلد `UPLOAD_DIR` ضمن النسخ الاحتياطية، أو استخدم Cloudinary.

### على Vercel

1. استورد المستودع، واضبط **Root Directory** على `web`.
2. أضف متغيرات البيئة: `DATABASE_URL` (PostgreSQL مُدار مثل Neon أو Supabase)، و`AUTH_SECRET`، و`NEXT_PUBLIC_SITE_URL`، و`STORAGE_DRIVER=cloudinary` مع مفاتيح Cloudinary، و`ANALYTICS_SALT`.
3. أمر البناء: `npx prisma migrate deploy && npm run build`.
4. شغّل `npm run db:seed` مرة واحدة من جهازك على قاعدة الإنتاج، مع `SEED_DEMO=false`.

### قائمة ما قبل الإطلاق

- [ ] `AUTH_SECRET` و `ANALYTICS_SALT` قيم عشوائية قوية
- [ ] `NEXT_PUBLIC_SITE_URL` هو النطاق الفعلي بـ https
- [ ] حذف المحتوى والحسابات التجريبية
- [ ] تحرير بيانات الكاتب والسيرة الذاتية وسياسة الخصوصية وشروط الاستخدام
- [ ] ضبط التخزين السحابي إن كانت الاستضافة بلا قرص دائم
- [ ] نسخ احتياطي دوري لقاعدة البيانات

## ملاحظات

- لا تُرسل النشرة البريدية رسائل بنفسها. يُجمع المشتركون ويُصدَّرون بصيغة CSV لاستيرادهم في Mailchimp أو Brevo أو غيرهما.
