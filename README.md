# TikTap 0.2.0
Arabic Android starter app to launch TikTok and run a configurable tap-timing test inside its own demo screen. It does not automate interaction or likes in third-party apps.

See README_AR.md for setup and build instructions. GitHub Actions builds a debug APK artifact.

## IRAQ TRAVEL web platform

This repository also contains **IRAQ TRAVEL** ("Discover the Land Between Two Rivers"), a multilingual Next.js + Supabase tourism platform for Iraq, in [`iraq-travel/`](iraq-travel/README.md). See that README for setup, the demo admin account, the database schema and deployment.
